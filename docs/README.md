# Documentation Hub

This folder stores documentation updated after each iteration.

## Internal Docs
- Architecture notes
- Development workflows
- Testing strategy
- Release and operations guidance
- PR workflow and checklist template: `.github/pull_request_template.md`

## External Docs
- End-user setup guides
- Feature guides
- Troubleshooting
- Changelog and release notes

## Update Rule
After each completed iteration:
1. Update internal technical docs for implementation details.
2. Update external docs for user-visible changes.
3. Record migration or upgrade notes when applicable.

## Current Baseline
- Active baseline branch pattern: `feature/<iter>-<slug>` from `develop`
- Iteration 00 spec: `plan/spec-00-hello-world.md`
